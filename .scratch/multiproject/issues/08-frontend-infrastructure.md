# 08 — 前端基础设施

**What to build:** 前端全局状态项目化。store 增加当前项目与项目列表；所有 API 请求自动带 `X-Project-Id`；事件流 URL 带项目上下文、缓存键项目化；管理员角色从 `user.is_admin` 读取；登录时序改为先确认项目归属再加载成员身份。

**Blocked by:** 01 — 项目上下文与 admin 全局化

**Status:** ready-for-agent

- [ ] store：当前项目与项目列表；成员记录变为当前项目成员；角色选择器（负责人/管理员/可管成员）跟随当前项目
- [ ] API 三个请求入口（普通请求/上传/下载）都自动带 `X-Project-Id`
- [ ] 事件流（SSE）URL 带项目上下文；前端缓存键含项目维度
- [ ] 管理员角色来源 `user.is_admin`（不再读成员记录里的 admin 角色）
- [ ] 登录时序：先取项目列表判断分流，再加载当前项目成员身份
