# 02 — 工作项项目化（tracer bullet）

**What to build:** 工作项（任务）带项目归属——这是第一个完整垂直切片，验证整套跨项目隔离机制。创建工作项自动归属当前项目上下文；列表/详情只返回当前项目的工作项；用项目 A 的上下文访问项目 B 的工作项返回 404；指派负责人只能选当前项目成员（跨项目返回 400）。

**Blocked by:** 01 — 项目上下文与 admin 全局化

**Status:** ready-for-agent

- [ ] 在项目 A 下创建的工作项落库时项目归属为 A
- [ ] 项目 A 的任务列表不含项目 B 的任务
- [ ] 用 A 的上下文访问 B 的工作项详情 → 404（不是 403）
- [ ] 跨项目指派（把 A 项目成员指派为 B 项目任务负责人）→ 400
- [ ] 工作项相关既有 API 测试在双项目 fixture 下全绿
