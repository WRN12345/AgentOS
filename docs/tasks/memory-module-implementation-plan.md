## M1 基础设施

### M1.1 pgvector 镜像切换

- 状态：已完成

**目标**：数据库支持向量存储，不引入新服务。

**内容**：`docker-compose.yml` 镜像换成 `pgvector/pgvector:pg16`（大版本不变）；沿用现有数据卷验证既有数据无恙；更新部署文档镜像说明。

**依赖**：无

**验收**：`docker compose up` 正常；既有迁移全部 apply；既有后端测试全绿。

**依赖**：无

**验收**：接口与配置就位，有基于 fake provider 的单测。

### M1.4 Ollama EmbeddingProvider 实现

- 状态：已完成（MockTransport 测试 8 项全绿；真实 Ollama 调用待宿主机 Ollama 环境就绪后验证）

**内容**：Ollama 实现；超时/不可用统一封装为可识别异常（供 M6.6 降级判断）；批量调用支持。

**验收**：真实调用返回向量；Ollama 停止时抛统一封装异常而非未处理异常；grep 不到业务代码直接实例化客户端。
